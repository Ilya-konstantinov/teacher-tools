# Teacher Tools

- [colloq_time](colloq_time/) — распределение студентов по времени коллоквиума с учётом заявок, подготовки и доступности принимающих; отчёт нагрузки.
- [colloq_tickets](colloq_tickets/) — генерация различных билетов с целевой сложностью и ограничениями тем; подготовка к печати и разрезанию.
